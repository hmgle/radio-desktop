# 用户指南

[English](user-guide.md) · [返回首页](../README.zh-CN.md)

## 浏览与播放

首次启动先获取热门电台，再后台同步 Radio Browser 完整目录；电台数量会随目录变化。下载失败时点击「更新目录」。缓存完成后可以离线浏览，播放仍需要网络。

搜索支持名称、国家/地区、语言和标签，可叠加国家/地区、语言、标签和最低码率筛选。下拉框内也能搜索候选项。使用「重置」或「清空搜索和筛选」解除限制，滚动列表可继续加载。

国家/地区下拉框支持代码、目录原名或简体中文名称的前缀，包括单个汉字。例如，输入
`中` 可找到本地目录中已有的中国、中非共和国等项，输入 `中国` 可进一步缩小范围。
也支持常用简称 `香港`、`澳门` 及其单字前缀 `香`、`澳`，候选仍显示完整名称。
选择候选后按对应地区代码筛选电台。中英文界面均支持中文名称匹配；中文界面的候选
和已选筛选按钮显示中文名称及代码，例如 `中国 (CN)`，切换语言时同步更新。英文界面
使用目录原名，中文界面遇到无法识别的代码也回退到目录原名。电台数和已保存的电台
元数据保持原值。语言、标签下拉框按目录值前缀匹配。

点击电台播放，底栏可播放/暂停、停止、收藏和调整音量。点击封面或电台信息展开详情。曲名、封面取决于广播方是否提供兼容元数据，缺少封面不代表播放失败。

「播放链接」临时试听 HTTP(S) 音频或 HLS 直链，不会保存到「我的电台」。不要填写电台网站页面。「添加电台」保存名称、流地址和可选主页。临时链接不能直接收藏，请先保存为自定义电台。删除自定义电台会移除该条目。

## 收藏、历史与设置

点击列表或播放器中的爱心切换收藏。「最近播放」最多保留 1000 条收听记录。「设置 → 清除播放历史」经确认后删除历史，不影响收藏、自定义电台和当前播放。

设置即时生效并保存在本地：

| 设置 | 行为 |
| --- | --- |
| 界面语言 | 跟随系统、英文、简体中文，同时更新菜单和托盘 |
| 主题 | 跟随系统、浅色、深色 |
| 播放动效 | 默认开启；关闭可降低 CPU 占用 |
| 启动行为 | 全新开始、恢复选择（默认）、恢复并播放；始终记忆音量 |
| 更新间隔 | 启动时检查目录年龄，默认 7 天；0 禁用自动更新，首次目录下载除外 |
| 关闭窗口 | 隐藏并继续播放（默认），或退出 |

睡眠定时器到期停止播放，切台后仍有效，退出应用后重置。

默认关闭窗口后继续播放，可从托盘重新打开、控制播放或退出。没有可用托盘时关闭窗口会退出。媒体键和 Now Playing 的支持取决于系统和桌面环境。

系统唤醒或网络恢复后，正在播放或连接的电台会按原有退避和候选地址限制重试。恢复信号不会自动拉起已暂停、停止或失败的播放；重试耗尽后请点击播放手动重试。系统已联网不代表目标电台一定可达。

## 快捷键

macOS 使用 Cmd，Linux 和 Windows 使用 Ctrl。

| 快捷键 | 操作 |
| --- | --- |
| 空格 | 在电台页面、非交互控件中播放/暂停 |
| ↑ / ↓、Enter | 选择电台、播放所选电台 |
| Cmd/Ctrl+F | 返回电台页面并聚焦搜索 |
| Cmd/Ctrl+N | 添加自定义电台 |
| Cmd/Ctrl+L | 播放链接 |
| Cmd/Ctrl+, | 打开设置 |
| Esc | 关闭对话框、电台详情或设置 |

筛选下拉框支持方向键、Home/End、Enter 和 Esc。系统或桌面环境可能拦截部分快捷键。

## 网络与本地数据

无需注册 Radio Desktop 账号。目录、收藏、自定义电台、历史、音量与偏好保存在 SQLite 数据库 `radio.db`：

| 系统 | 默认目录 |
| --- | --- |
| macOS | `~/Library/Application Support/radio-desktop/` |
| Linux | `${XDG_CONFIG_HOME:-~/.config}/radio-desktop/` |
| Windows | `%APPDATA%\radio-desktop\` |

备份或恢复前，先**完全退出应用**，再复制整个目录，包括可能残留的 `radio.db-wal`、`radio.db-shm`。隐藏窗口不等于退出。目前没有内置导入导出或云同步。

网络请求包括 Radio Browser 服务器发现与目录下载、目录电台成功起播后的点击上报、音频流、适用时的额外 ICY 元数据连接，以及台标和曲目封面。hls.js 加载的 HLS 资源通过 Go 后端获取。服务方可看到 IP 和相应请求，缓存目录的搜索在本地完成。部分音频流使用未加密的 HTTP。

目录由 Radio Browser 社区维护，电台可用性、信息准确性和广播内容权利由相关提供方负责。

更新应用时，先完全退出，再从 [GitHub Releases](https://github.com/hmgle/radio-desktop/releases/latest) 下载同平台、同架构的新版安装包安装；Linux `.deb` 安装使用包管理器更新。正常升级保留上述数据目录，必要时请先备份。目前没有应用内自动更新。

### 网络代理

应用自动读取系统代理，目前没有独立的代理开关或地址设置。无需代理的用户可以直接使用；需要代理的用户可在操作系统中配置代理。

目录发现、目录同步、点击上报、ICY 曲目信息、系统媒体封面及 hls.js 的请求都自动使用 MyGo 的代理解析：显式代理环境变量优先，否则读取系统代理，本机回环地址始终直连。需要通过环境变量配置时，请分别设置 `HTTP_PROXY`、`HTTPS_PROXY`，按需配置 `NO_PROXY`（也支持小写形式）；不要仅设置 `ALL_PROXY`。从桌面图标启动时，不一定继承终端里的变量。

普通音频、原生 HLS 和界面图片由系统 WebView 或媒体组件联网，其代理支持取决于平台。仅设置 Go 请求的代理环境变量，不能保证这些请求也使用同一代理。配置系统代理后，请分别验证目录、播放和图片；这版应用尚不提供覆盖所有请求的独立代理设置。

系统代理更改会用于后续 Go 请求，解析结果可能缓存约 5 秒；正在播放的连接不会立即迁移。更改后可重新连接电台或重试目录同步。若目录正常但某些电台失败，还需检查代理规则、出口地区及广播方的地区限制。

## 常见问题

| 现象 | 建议 |
| --- | --- |
| 目录为空 | 检查网络、点击更新目录、清空搜索与筛选；如有错误详情可展开查看。 |
| 单个电台无法播放 | 尝试其他电台或广播方最新直链，部分流有地区限制。 |
| 大量电台无法播放 | 检查音量、输出设备、网络与 WebView 编解码器；确认使用音频直链。 |
| HLS 失败 | 需要原生 HLS，或 MediaSource 与兼容解码器；hls.js 无法补足缺失的系统解码器。 |
| Linux 无法启动 | 安装 WebKitGTK 4.1、GTK 3 和 libpulse，在图形会话中从终端启动查看错误。 |
| Linux 无法播放 MP3/AAC | 检查发行版的 GStreamer 编解码插件，通常涉及 plugins-good、plugins-bad、libav，名称和可用性因发行版而异。 |
| 关闭窗口仍有声音 | 默认为隐藏到托盘，请选择退出或修改关闭行为。 |
| 缺少托盘或媒体控制 | 检查桌面环境的托盘/MPRIS 支持及扩展。 |
| 播放时 CPU 占用高 | 在设置中关闭播放动效，并尝试其他流格式。 |
| 目录更新被拒绝 | 新目录数量骤降超过 25% 时保留旧目录，请稍后重试。 |

反馈问题请附系统、架构、应用版本、复现步骤与错误详情。分享前移除令牌、私有流地址和个人信息，详见[贡献指南](../CONTRIBUTING.md)（英文）。
