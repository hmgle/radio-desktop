# Screenshots

Captured on 2026-11-05 from the Linux desktop build (version 0.1.0), using a
1200 × 820 window and the light theme. Each README shows two typical views
in its own language:

| View | English | Simplified Chinese |
| --- | --- | --- |
| Station browser and player | `stations-light.png` | `stations-zh-CN.png` |
| Settings | `settings.png` | `settings-zh-CN.png` |

The capture used a separate profile containing the public Radio Browser
catalog, with personal favorites, history, custom stations, and preferences
removed. Playback was muted. The images show the actual WebKitGTK application,
not a mockup; window controls and fonts vary across platforms.

To refresh them, build the current app, launch with an isolated profile,
choose the matching interface language in Settings, and capture only the app
window. Use a public station, avoid private URLs and personal listening data,
and update both READMEs if image names change. Station logos and broadcast
metadata remain the property of their respective providers.
